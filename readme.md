## Knowledgenet Example Rules Project:

This is an example project for demonstrating the use of rules authoring using Knowledgenet rules engine. Each example is in a subdirectory under this directory. Read the readme.md for more information on the example and how to set things up.

Currently, this project has one example - rules execution for an auto-insurance claim adjudication system. For received claims, the rules are executed to determine if the claims should be paid or denied. For more details, read the [autoins/doc/description.md](autoins/doc/description.md){:target="_blank"}.
