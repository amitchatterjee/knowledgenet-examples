# testing-guidelines

Documentation of test artifact formats and workflow for `autoins` (e.g. `autoins/docs/testing.md`'s EDI
format, `expected.csv` schema, the "write data → run → dump_result → promote to expected" workflow).
Split out from `application-architecture`: different lifecycle/owner than the app's code architecture,
and maps directly to the test-generator subagent's dedicated grounding context.

Status: scaffold only, content not yet curated.
